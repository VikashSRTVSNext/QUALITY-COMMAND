
# Project Instructions

## Token Efficiency
- Keep responses short and technical.
- Avoid unnecessary explanations and repetition.
- Inspect only relevant files.
- Use targeted searches; never scan the entire repository without reason.
- Read only required file sections.
- Summarize large logs, JSON, API responses and datasets.
- Avoid repeating previously gathered context.
- Batch independent tool calls.
- Avoid unnecessary subagents.

## Development Rules
- Understand existing architecture before modifying code.
- Reuse existing utilities, components and patterns.
- Avoid unrelated refactoring.
- Preserve API contracts, business logic and naming conventions.
- Do not introduce unnecessary dependencies.
- Handle errors and edge cases.
- Keep code maintainable and production-ready.

## Verification
- Run relevant tests after changes.
- Check affected files for regressions.
- Report changed files, test results and blockers only.
- Never claim tests passed without running them.
